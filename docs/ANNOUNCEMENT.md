# Forever for Mac：为 macOS 定制的一站式魔兽插件助手

想在 Mac 上把魔兽插件、界面组合和插件开发一起管起来，可以试试 **Forever for Mac**。

它把这些事情放进一个原生 Mac 窗口：

- 接管国服《无限》已有插件，按整合包管理模块。
- 检查作者更新，先看变更，再备份应用；有问题可以恢复和回滚。
- 按角色切换 EllesmereUI / ForeverUI，各自保留配置。
- 接上已有的 Codex、Claude Code 或 Cursor，在离线副本里改插件，检查 Lua、打包，再生成安装计划。
- 从助手打开战网，沿用战网登录态进入游戏。

**定位很明确：为 macOS 定制的一站式插件助手。**

目前是源码预览版，已在 Intel Mac 验证；游戏内加载与战斗表现还需要玩家验收。欢迎 Mac 玩家试用、反馈。
